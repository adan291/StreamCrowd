# StreamCrowd - Guía de Componentes

Este documento se mantiene automáticamente sincronizado con los cambios en los componentes mediante hooks de Kiro.

## Componentes Principales

### Componentes de Actividad
- **ActivityStats**: Muestra estadísticas de la actividad del stream
- **EventFeed**: Feed de eventos en tiempo real
- **ViewerPanel**: Panel de información de viewers

### Componentes de Comandos
- **CommandBlock**: Bloque individual de comando
- **CommandPanel**: Panel principal de gestión de comandos
- **VisualCommandEditor**: Editor visual de comandos

### Componentes de Colaboración
- **CollaborationPanel**: Panel principal de colaboración
- **InviteModal**: Modal para invitar colaboradores
- **RoleManager**: Gestor de roles y permisos
