## Sitios recomendados (gratuitos, sin registro):

- **Pixabay**: https://pixabay.com/sound-effects/
- **Mixkit**: https://mixkit.co/free-sound-effects/
- **Freesound** (requiere cuenta): https://freesound.org/

## Notas:
- Los archivos deben ser MP3
- Si no encuentras un archivo, el panel usará un sonido sintético como fallback
- Mantén los archivos pequeños (< 500KB cada uno) para carga rápida
