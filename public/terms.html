Términos de Servicio

Última actualización: Enero 2026

1. Aceptación de los términos

Al usar StreamCrowd, aceptas estos términos de servicio.

2. Descripción del servicio

StreamCrowd es una herramienta gratuita que permite a streamers visualizar y gestionar el chat de múltiples plataformas (YouTube, Twitch) en una sola interfaz.

3. Uso aceptable

Te comprometes a:

  • Usar el servicio de acuerdo con las políticas de YouTube y Twitch
  • No usar la aplicación para spam, acoso o actividades ilegales
  • No intentar acceder a cuentas de otros usuarios

4. Propiedad intelectual

StreamCrowd es software de código abierto. El código está disponible bajo su respectiva licencia en GitHub.

5. Limitación de responsabilidad

StreamCrowd se proporciona "tal cual", sin garantías. No somos responsables de:

  • Interrupciones del servicio de YouTube o Twitch
  • Pérdida de datos en tu navegador
  • Cambios en las APIs de terceros

6. Modificaciones

Podemos actualizar estos términos en cualquier momento. Los cambios se publicarán en esta página.
