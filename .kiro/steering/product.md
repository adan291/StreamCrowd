# StreamCrowd Product Overview

StreamCrowd is a comprehensive interactive streaming toolkit designed for content creators on Twitch, YouTube, and Kick. It combines real-time audience engagement tools with advanced analytics and automation features.

## Core Features

- **Interactive Polls**: Real-time voting with customizable options, colors, and overlays
- **Advanced Giveaways**: Multiple modes (viewers, keyword, subscribers) with weighted entries
- **Judge Panel**: Multi-criteria evaluation system for competitions and contests
- **13+ Mini-Games**: Including Casino Roulette, Chat Fishing, Duck Hunt, Battleship, and more
- **Twitch Predictions**: Native integration with Twitch's prediction system
- **Channel Points**: Complete management of Twitch channel point rewards
- **AI Analytics**: Sentiment analysis, engagement metrics, and viewer insights
- **Macro System**: Automation with triggers for chat commands, events, and schedules
- **OBS Integration**: WebSocket control with overlay support and scene management
- **Multi-Platform**: Web app (PWA) and desktop (Electron) versions

## Target Audience

Primary users are streamers and content creators who want to increase audience engagement through interactive features. The application supports both individual streamers and collaborative streaming scenarios with moderator support.

## Technical Architecture

Built as a modern React application with TypeScript, following hexagonal architecture principles. Supports both online (Firebase sync) and offline modes with IndexedDB storage. Features comprehensive internationalization (Spanish/English) and accessibility compliance.

## Key Differentiators

- All-in-one solution combining multiple engagement tools
- Real-time synchronization across multiple devices
- Advanced moderation and filtering capabilities
- Extensive customization options for overlays and interactions
- Property-based testing for reliability
- Comprehensive macro and automation system
